# AIOS v3.0 宪法结构索引

AIOS v3.0采用模块化宪法结构。

原则：一个核心机制对应一个独立文件。

## 核心模块

- Core Principles
- Data Acquisition
- Data Cleaning
- Base Dimension
- Dimension Summary
- Dimension Registration
- User AI Interaction Dimension
- Long Context Continuity
- Event Dimension
- Basic Cognition Dimension
- High Level Cognition Dimension
- AI Dimension
- Entity System
- Evidence Revision System
- Goal Task System
- Action System

## 模块关系原则

模块之间通过引用连接，不重复定义。

所有维度在世界中平级存在。

总结机制属于所有维度共有能力。

维度注册属于 AIOS 世界扩展能力。

认知模块负责理解，不负责替代事实。
