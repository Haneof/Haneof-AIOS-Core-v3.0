# AIOS v3.0 AI维度模块索引

AI维度作为统一多维世界中的一组平级认知维度，不建立独立 AI 数据库。

## AI维度模块

```text
AI Dimension

├── AI User Understanding Model
│   └── AI对用户世界的理解
│
├── AI Relationship Model
│   └── AI与用户关系理解
│
├── AI Self Model
│   └── AI对自身存在、能力、经历的理解
│
├── AI Intent Model
│   └── AI主动关注、探索、验证方向
│
├── AI Strategy Model
│   └── 针对用户的有效交互与帮助策略
│
├── AI Cognitive Boundary Model
│   └── 已知、未知、假设、待验证
│
├── AI Personality Model
│   └── AI长期交互形成的稳定行为特征
│
└── AI Calibration Model
    └── AI对过去判断、反馈、错误与有效性的校准
```

## 统一世界实现原则

所有 AI维度模块：

- 都是统一 WorldStore 中的世界对象；
- 默认使用 EvidenceSet + Claim + Dependency 表达可修正认知；
- 使用统一 Revision / Retraction / Propagation 机制；
- 使用统一智能世界索引；
- 遵循统一时间总结机制；
- 不创建第二套 AI Self / Relationship / User Profile 真相库。

模块名称只是认知视图边界，不是数据库层级。
