# AIOS v3.0 宪法模块清单

## 文档治理

AIOS v3.0采用模块化宪法结构。

原则：一个核心机制对应一个独立文件。

模块之间通过引用连接，不重复定义。

---

## 核心模块

- Core Principles
- Data Acquisition
- Data Cleaning
- Base Dimension
- Dimension Summary
- Dimension Registration
- User AI Interaction Dimension
- Long Context Continuity
- Event Dimension
- Basic Cognition Dimension
- High Level Cognition Dimension
- AI Dimension
- Entity System
- Evidence Revision System
- Goal Task System
- Action System

---

## 世界模型原则

- 所有维度存在于同一个多维世界。
- 维度之间为平级观察轴，不是数据库上下级。
- 新维度是新的观察角度，不替代已有维度。
- 总结机制属于所有维度共有能力。
- 维度注册属于世界扩展能力。

---

## 治理原则

- 事实记录与认知理解分离。
- 总结与认知分离。
- 机制定义只存在于对应模块文件。
- 历史入口文件不再承载新增机制。
