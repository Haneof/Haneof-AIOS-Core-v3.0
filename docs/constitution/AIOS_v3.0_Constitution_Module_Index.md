# AIOS v3.0 Constitution Module Index

## 模块化原则

AIOS v3.0 宪法采用机制拆分方式。

原则：

- 一个核心机制对应一个文件。
- 文件之间通过引用关联，不重复定义。
- 维度、总结、认知、注册、证据等机制保持独立边界。
