# AIOS v3.0 Constitution Final Entry Map

## Purpose

Define the final legal/document entry structure of AIOS v3.0 constitution.

## Official Entry

AIOS v3.0 uses:

- Version Entry as release entry.
- Structure Index as module navigation entry.
- Individual mechanism files as authoritative definitions.

## Authority Rules

1. A mechanism definition exists only in its dedicated file.
2. Entry files do not redefine mechanisms.
3. Historical combined documents are references only.
4. New mechanisms must create independent constitution files.

## Dimension Model

All dimensions exist in the same multi-dimensional world.

Dimensions are parallel observation axes, not hierarchical database layers.
