# AIOS v3.0 文档治理宪法

## 第一条：模块化原则

AIOS v3.0 宪法采用模块化结构。

一个核心机制对应一个独立文件。

文件之间通过引用连接，不重复定义同一机制。

---

## 第二条：职责隔离原则

每个模块只负责自身范围：

- 数据模块负责数据进入与整理；
- 维度模块负责世界观察轴；
- 总结模块负责时间结构；
- 认知模块负责理解；
- 注册模块负责世界扩展；
- AI模块负责AI自身状态。

任何模块不得替代其他模块职责。

---

## 第三条：事实与理解隔离

事实记录、总结结果、认知结果必须保持边界。

事实不可因为认知变化而修改。

认知可以随着新证据调整。

---

## 第四条：新增机制规则

后续新增能力必须：

1. 明确所属机制；
2. 创建独立文档；
3. 建立与现有模块关系；
4. 避免向综合文件无限堆积。

---

## 第五条：历史文件管理

旧版综合文件保留作为历史记录或入口说明。

新增规则不得继续写入旧版综合文件。
