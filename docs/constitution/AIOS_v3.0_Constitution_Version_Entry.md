## 宪法结构

AIOS v3.0 采用模块化宪法体系：

- 一个核心机制对应一个独立文件；
- 模块之间通过引用连接；
- 所有维度属于同一个多维世界；
- 维度之间平级存在；
- 运行职责层不等于世界层级。

## 维护原则

融合阶段：

1. 旧仓已有成熟实现不得因“来自旧仓”自动废弃；
2. 新仓文档不得因“更新”自动拥有绝对优先权；
3. 双方冲突时必须形成机制级裁决；
4. 认知类能力必须由真实大模型运行验证；
5. 只有融合、迁移、入住测试完成后才能重新标记 FINAL。
