# AIOS v3.0 宪法版本入口

## 版本

AIOS v3.0

## 宪法结构

AIOS v3.0 采用模块化宪法体系。

核心原则：

- 一个核心机制对应一个独立文件；
- 模块之间通过引用连接；
- 不重复定义机制；
- 所有维度属于同一个多维世界；
- 维度之间平级存在。

## 核心模块入口

- Core Principles
- Data Acquisition
- Data Cleaning
- Base Dimension
- Dimension Summary
- Dimension Registration
- User AI Interaction Dimension
- Long Context Continuity
- Event Dimension
- Basic Cognition Dimension
- High Level Cognition Dimension
- AI Dimension
- Entity System
- Evidence Revision System
- Goal Task System
- Action System

## 维护原则

后续新增机制必须创建独立模块文件，并更新结构索引。

禁止恢复旧版综合文件承载全部机制定义。
