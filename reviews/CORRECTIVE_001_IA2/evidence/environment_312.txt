# captured: 2026-09-28T12:57:45Z

## How this interpreter was provisioned
The earlier report claimed 3.12.14 was unobtainable. That was FALSE and is retracted:
codeload.github.com is reachable.  Prebuilt-binary routes (astral.sh/uv,
release-assets.githubusercontent.com, conda, deb.debian.org) are blocked, but the
CPython source tarball is not.

  curl https://codeload.github.com/python/cpython/tar.gz/refs/tags/v3.12.14 -> HTTP 200, 27777501 bytes

The real blocker was missing C headers: sqlite3.h and ffi.h exist nowhere on this
filesystem, and only versioned runtime .so files were present (no -dev packages,
no apt mirror).  Resolved by building a dependency prefix from source:

  SQLite amalgamation  3.38.2  -> /home/user/py312deps/lib/libsqlite3.so.0.8.6
      (azadkuh/sqlite-amalgamation master; its newest tag is 3.38.2)
      built shared, not static: configure's bare '-lsqlite3' link test FAILS
      against a static archive lacking -lm/-ldl/-lpthread, and _sqlite3 is then
      silently omitted.  Self-check program printed: sqlite compile=3.38.2 lib=3.38.2
  zlib                 1.3.1   -> /home/user/py312deps/lib/libz.so.1.3.1
  pkg-config           absent  -> a 20-line shell stub answering sqlite3/zlib only
                                   (real variable expansion of prefix/includedir/libdir)
  autoconf             absent  -> not needed; the GitHub tag tarball ships a
                                   pregenerated ./configure (872895 bytes)

  ./configure --prefix=/home/user/py312 --with-ensurepip=install \
      CPPFLAGS=-I/home/user/py312deps/include \
      LDFLAGS='-L/home/user/py312deps/lib -Wl,-rpath,/home/user/py312deps/lib'
  configure reported: 'checking for sqlite3_bind_double in -lsqlite3... yes'
                      'checking for stdlib extension module _sqlite3... yes'
                      'checking for stdlib extension module zlib... yes'
  make -j2 exit=0 ; make install exit=0

  14 optional modules were NOT built (no headers): _bz2 _ctypes _ctypes_test
  _curses _curses_panel _dbm _gdbm _hashlib _lzma _ssl _tkinter _uuid nis readline
  _ssl absent means no TLS, so wheels were fetched with the 3.11 venv's pip
  (--python-version 312 --only-binary=:all:) and installed with --no-index.
