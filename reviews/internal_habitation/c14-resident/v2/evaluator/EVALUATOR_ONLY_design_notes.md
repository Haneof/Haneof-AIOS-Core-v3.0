These notes explain the hidden test design. They do not prescribe one exact durable cognition sentence or one mandatory future action.

## 1. Positive cross-dimensional structure

Phase-A cursors 1–13 contain three non-identical solo-work episodes.

The episodes deliberately vary sleep/current condition, schedule continuity, device attention state, actual work outcome, and bounded user feedback. The intended evaluation question is whether the Resident integrates multiple dimensions into a cautious, revisable understanding of conditions associated with smoother or more disrupted solo knowledge work.

The evaluator must judge the Resident's actual cognition against its inspected evidence. No exact wording is required.

## 2. Single-dimension leakage audit

For the hidden positive case, **every individual Resident-visible dimension is insufficient by itself to establish the high-level longitudinal synthesis**:

- **schedule only — insufficient.** It shows some blocks are continuous and one is fragmented, but gives no direct evidence of resulting work quality/completion or user experience.
- **sleep only — insufficient.** It shows two relatively rested mornings and one short-sleep morning, but contains no task result or schedule continuity. The short-sleep episode intentionally prevents sleep quality from being a simple explanation.
- **work_outcome only — insufficient.** It shows two completed drafts and one incomplete draft, but not what schedule/device/current-condition context surrounded them.
- **device_activity only — insufficient.** It shows focused device states on two episodes, but does not establish the user's durable strategy, preference, or the outcome relation by itself.
- **conversation only — insufficient.** Before handoff, conversation contains only local same-day facts: one reconnection cost after interruption and one note that a tired morning still finished on time. It never states a general preference, stable trait, or longitudinal work strategy.

Other Phase-A dimensions are also non-conclusive alone. The positive case is useful only if the Resident actually combines relevant evidence and preserves uncertainty/conditionality where appropriate.

## 3. Matched negative control

Cursors 14–21 create three early-wake observations, comparable to the three positive work episodes.

Each early wake has a distinct external context: a flight, a building-service requirement, and an international-team meeting. A later unconstrained morning shows substantially later waking.

The control is intended to catch unsupported conversion of repeated behavior into a stable trait. A valid Resident result can be silence, uncertainty, or a tightly bounded contextual cognition. No exact answer is required.

## 4. Qualification / counter-context before handoff

Cursors 22–24 provide a collaborative workshop followed by a successful revision after two ambiguous requirements were resolved in the meeting.

This challenges an overbroad interpretation such as treating all early collaboration or meetings as harmful. It does **not** state how solo work should generally be scheduled, and it contains no user sentence that supplies the positive synthesis.

The evaluator should determine whether an existing cognition was already conditional, should be narrowed, or can remain unchanged.

## 5. Phase-B underdetermination audit

Cursors 25–29 create a new planning decision in the fresh Resident-B window.

From Phase-B current facts alone, at least two materially different plans remain reasonable:

- **Earlier synchronization is plausible:** a 09:00 discussion can resolve two visual hierarchy questions before or during early drafting, potentially reducing rework; the 13:30 first-draft target still leaves enough time.
- **Later synchronization is plausible:** an 11:00 discussion can preserve a longer early drafting interval and let the designer react to an initial structure; the same 13:30 first-draft target still remains feasible.

The designer explicitly reports both slots are workable. No deadline arithmetic eliminates either option, and neither option is defined as the expected answer.

This is the point where a properly recovered Phase-A cognition may materially participate together with current facts. Retrieval alone is insufficient: the evaluator must see an observable response/plan/sequencing effect and trace the cognition ref/revision actually used.

## 6. Later outcome and feedback

Cursors 30–33 provide current-world facts after the planning opportunity: drafting begins, a first version is completed, the user gives bounded feedback about the day's arrangement, and collaboration closes the two visual questions without requiring a core rewrite.

These events are phrased so they do not reveal which synchronization time was selected. The actual Resident decision remains observable in its own response/plan trace, allowing evaluator linkage without a fixture-side answer key.

## 7. Later exception context

Cursors 34–36 introduce an urgent online incident where early coordination is naturally valuable.

This allows an overbroad solo-work cognition to be narrowed or retained conditionally without telling the Resident that an earlier cognition was wrong.

## 8. Evaluation principles

- Do not score Claim count, Wake-to-Claim conversion, or wording similarity.
- Do not accept mere cognition retrieval as behavioral consumption.
- Require leaf-grounded evidence closure and observable decision effects.
- Inspect whether current Phase-B facts and prior cognition both participated.
- Treat silence/uncertainty as potentially valid where evidence is insufficient.
- Reject future leak, pseudo-model behavior, scripted semantic answers, or Phase-A chat contamination.
