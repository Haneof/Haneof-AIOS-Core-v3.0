## Before-fix reproduction

Cover Wake and Periodic Review separately.

## Required semantics

Introduce the minimum durable model-attempt admission/provenance needed for non-user-turn Resident executions.

The system must distinguish at least:
- definitely not submitted / retryable;
- submitted or possibly submitted but outcome unknown = `UNKNOWN/IN_DOUBT`;
- provider/model response durably returned;
- reconciled terminal state.

A RUNNING Wake/Review alone must never be treated as proof that provider re-invocation is safe.

Admission must exist before provider dispatch. Durable completion/provenance must be recorded immediately after a valid model return. Ambiguous failure must fail closed and prevent blind reinvocation.

Reuse/integrate the existing MeteringLedger and runtime persistence. Do not create a second hidden truth store.

## Required crash-window tests

At minimum:
- failure before provider dispatch;
- failure/timeout after possible dispatch but before response;
- response returned then crash before metering/attempt completion boundary;
- metering/attempt receipt durable then crash before Wake completion;
- restart of RUNNING Wake;
- restart of RUNNING Periodic Review;
- explicit retry only when durable evidence proves non-submission.

Preserve existing exactly-once Wake user-delivery recovery.
