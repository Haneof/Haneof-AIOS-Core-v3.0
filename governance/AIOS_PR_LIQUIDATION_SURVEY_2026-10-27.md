## 二、开放 PR 盘点：85 个候选

### 方法（可复现，不依赖 API 配额）

`gh auth` 未登录、`api.github.com` 对当前出口 IP 已触发 rate limit，
所以改用 **git 协议侧的可核实信号**：

- GitHub 为**开放** PR 维护 `refs/pull/N/merge`（自动合并预览提交）。
- PR 一旦 closed/merged，该 ref 被移除；`refs/pull/N/head` 则长期保留。
- 因此 **有 merge ref ⇒ 极大概率 OPEN**。

```bash
git ls-remote origin 'refs/pull/*/merge' | wc -l   # → 85
git ls-remote origin 'refs/pull/*/head'  | wc -l   # → 383
```
